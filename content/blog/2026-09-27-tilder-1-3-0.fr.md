## Nom

tilder 1.3.0 - un accent au choix, et du code coloré dans ansi/

tilder 1.3.0 est sorti, et le site est construit avec. L'image est
`ghcr.io/thosted/tilder:1.3.0`.

## Un accent réglable

La couleur d'accent unique du miroir en texte coloré - les liens, les
`[ tags ]`, les puces de liste, le `code` en ligne, les lignes de
commande, l'encadré INFO - était toujours cyan. `[text] accent` la
règle désormais : l'un des huit noms de couleur, ou un index de 256
couleurs de 16 à 255, tel que `208` pour l'orange. Un `site.<lang>.toml`
peut régler le sien ; toute autre valeur arrête la construction. Ce site
règle son accent à `208`, pour retrouver son propre orange
([configuration](docs/reference/configuration)).

```toml
[text]
accent = 208
```

## Des blocs de code colorés dans ansi/

Un bloc de code dans un langage que `highlight.py` connaît est
désormais aussi coloré dans le miroir en couleur, chaque composant dans
la couleur de son genre, selon les mêmes règles que la page HTML : les
mots-clés et, en `sh` et `console`, le mot de commande, en gras dans la
couleur d'accent ; les identifiants natifs, les types et les options
dans la couleur d'accent ; les chaînes et les lignes ajoutées d'un
`diff` en vert ; les commentaires et une invite `console` atténués ;
les nombres et les variables en magenta ; les étiquettes, les clés et
l'en-tête d'un extrait `diff` en gras ; les lignes retirées d'un `diff`
en rouge. Seule la couleur change, jamais un caractère ajouté : `txt/`
reste exactement aussi brut qu'avant
([le miroir en texte](docs/reference/text-mirror)).

## Une petite correction

Une URL ou une ligne de commande ne colore plus la ponctuation qui
referme la phrase autour d'elle : un `.` final, ou une `)` qui ferme une
parenthèse ouverte avant l'adresse.
