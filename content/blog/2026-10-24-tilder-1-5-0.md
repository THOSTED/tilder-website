## Name

tilder 1.5.0 - diagrams, a preview per page, scheduled posts, event maps

tilder 1.5.0 is out, and the site is built with it. The image is
`ghcr.io/thosted/tilder:1.5.0`.

## Diagrams, drawn at build time

A ```` ```d2 ```` fence, with a description for screen readers and an
optional caption, is drawn by D2 into an SVG
file at build time, in the theme's colours - light and dark, taken from
`style.css` - and its fonts. Nothing generated is committed; drawings are
cached, so a rebuild redraws only what changed. D2 ships in the image,
which grows from 75.6 MB to 118 MB
([diagrams](docs/reference/markdown/links-and-images#diagrams)).

The text mirror shows the D2 source, or a drawing made by hand, in a
text block marked `{text}` right after the diagram marked `{html}`.

## Where a block shows: {html} and {text}

The section markers now work on code blocks too: `{html}` at the end of
a fence's opening line keeps the block to the web page, `{text}` to the
text mirror; no marker shows it in both
([where a block shows](docs/reference/markdown/blocks#where-a-block-shows)).

## A share preview for every page

Each page gets its own 1200x630 card, drawn from the theme's
`share-page.svg`: its title, path, date, place or author, and tags
(`share_tags`). `share_title` and `share_detail` shorten what does not
fit; `image:` still forces a hand-made picture
([feeds and images](docs/reference/feeds-and-images)).

## Scheduled posts

A post dated after the build's date stays out of everything - page, list,
feeds, sitemap, text mirror - until that day; the midnight rebuild
publishes it. `BUILD_TODAY` previews a future day. This is on by default
for posts; `scheduled = false` in a collection turns it off
([scheduled posts](docs/content-types/post#scheduled-posts)).

## A static map for events

With `[maps] enabled = true`, an event with coordinates gets a map drawn
at build time from OpenStreetMap tiles, cached and served from the site:
no third-party request from visitors
([events](docs/content-types/event)).
