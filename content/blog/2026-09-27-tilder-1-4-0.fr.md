## Nom

tilder 1.4.0 - trois langages de plus colorés, jsonc, kyaml et markdown

tilder 1.4.0 est sorti, et le site est construit avec. L'image est
`ghcr.io/thosted/tilder:1.4.0`. Tout langage que `highlight.py`
connaissait déjà se rend exactement comme avant.

## jsonc, du JSON avec des commentaires

`jsonc`, alias `json-with-comments`, est du JSON avec des commentaires
`//` et `/* */`, le dialecte du `settings.json` et du `tsconfig.json`
de VS Code. Un commentaire est coloré comme n'importe quel autre, seul
sur sa ligne ou après une valeur ; le reste se colore exactement comme
`json`.

```jsonc
{
  // les réglages du thème
  "editor.tabSize": 2,
  "files.trimTrailingWhitespace": true /* garde les diffs courts */
}
```

## kyaml, le YAML strict de Kubernetes

`kyaml`, alias `kyml`, est le KYAML de Kubernetes : uniquement le style
de flux, des valeurs entre guillemets, un commentaire `#`. La
ponctuation reste brute, comme dans `yaml` et `json`.

```kyaml
apiVersion: "v1"
kind: "ConfigMap"
metadata: {"name": "site-config"}
data: {"accent": "208"}
```

## markdown, ce dialecte

`markdown`, alias `md` et `mdown`, colore le dialecte propre de tilder :
les clés du front matter et les `---` qui l'entourent, les titres et les
`{marqueurs}` qui les terminent, les clôtures (le code d'un bloc
clôturé reste brut, sans imbrication), les commentaires, les règles,
les barres d'un tableau, le `>` d'une citation et ses encarts
`[!GENRE]`, `[TOC]`, les puces de liste et les cases à cocher, et,
dans chaque ligne, le `code` en ligne, l'emphase, et la cible d'un lien
ou d'une image. Les pages de cette référence montrent désormais leurs
blocs source ainsi
([blocs](docs/reference/markdown/blocks)).

```markdown
---
title: About
description: Who writes this site and why.
---

## Name

about - who writes this site

- [x] a task, done
- [ ] a task, still to do

> [!INFO]
> Read the front matter first.
```
