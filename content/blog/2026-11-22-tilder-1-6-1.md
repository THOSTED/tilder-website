## Name

tilder 1.6.1 - an item's files follow its page behind item_prefix

tilder 1.6.1 is out, and the site is built with it. The image is
`ghcr.io/thosted/tilder:1.6.1`.

## An item's files follow its page

With `item_prefix = "-"`, tilder 1.6.0 moved a post's page to
`/blog/-/<slug>`, but the files of its folder - an image, a PDF - stayed
at `/blog/<slug>/...`: one post, two URL prefixes. They are now written
beside the page, at `/blog/-/<slug>/...`, for every collection with an
`item_prefix`. An image's path and the share image named by `image:`
follow; a link to a file of the folder is written with the prefix too,
`blog/-/<slug>/slides.pdf`. Without `item_prefix`, nothing moves
([configuration](docs/reference/configuration)).

A site already online with an `item_prefix` should redirect the old file
URLs with a 301, as it does for its pages. With Caddy:

```text
@movedfile path_regexp movedfile ^/(blog|events)/(\d{4}-\d{2}-\d{2}-[^/.]+)/(.+)$
redir @movedfile /{re.movedfile.1}/-/{re.movedfile.2}/{re.movedfile.3} permanent
```
